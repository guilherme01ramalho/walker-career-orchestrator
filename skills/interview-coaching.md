# Protocolo de Preparação para Entrevistas (COACH)

O objetivo desta skill é preparar o usuário para processos seletivos, integrando seu perfil profissional e as demandas do mercado.

## Processo de Preparação

1. **Contextualização:**
   - Leia `data/user-profile.md` para entender o perfil (área, nível, habilidades).
   - Leia `data/job-search-results.md` (se existir) para identificar tecnologias e requisitos valorizados pelas vagas encontradas.

2. **Diagnóstico:**
   - Cruze o perfil do usuário com os requisitos das vagas.
   - Identifique lacunas de experiência ou habilidades.
   - Prepare pontos de destaque (soft skills e hard skills) que o usuário deve enfatizar.

3. **Modos de Atuação:**

   ### Modo 1: Dicas para Entrevistas
   - Forneça recomendações sobre apresentação, comunicação e estruturação de respostas.
   - Liste perguntas comuns da área de atuação do usuário.
   - Destaque erros comuns a evitar.

   ### Modo 2: Simulação de Entrevista
   - Execute o fluxo de pergunta única por vez.
   - Avalie cada resposta individualmente e forneça feedback construtivo.
   - Ao final, compile uma avaliação geral.

4. **Registro:**
   - Salve todo o progresso e resultados da simulação em `data/interview-results.md`.
